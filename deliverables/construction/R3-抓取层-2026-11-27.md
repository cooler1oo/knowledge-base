## 二、模块职责与关键决策

| 文件 | 职责 | 为什么不合并 |
|---|---|---|
| `normalize.py` | 三种 `media` 形状归一、毫秒→秒、类型判定 | 纯函数、零依赖、16 个用例 0.06 秒跑完 |
| `router.py` | 域名路由、失败降级 | 依赖协议而非具体实现，测试塞假 hub |
| `parsehub_adapter.py` | 惰性单例、异常透传 | 换 §4.9 的 CDP 退路时只改这一个文件 |

### 2.1 `duration` 必须 `// 1000`

源码注释写「单位: 秒」是**错的**。实测 `445071` 按毫秒是 7.4 分钟、按秒是 123.6 小时。
写库列叫 `props.duration_sec`，不换算会把 7 分钟视频记成 5 天。

用断言钉住，不靠注释：

```python
assert 0 < media.duration_sec < 3600, (
    f"时长不合理，可能没做毫秒换算：{media.duration_sec}"
)
```

### 2.2 `None` 与 `0` 不能混

图文的 `ImageRef` 没有 `duration` 字段 → `duration_sec=None`。
若给 0，界面会显示「时长 0 秒」，那是错误信息不是缺失信息。

### 2.3 小红书：入口接受 ≠ 内容抓得到

AGENTS.md 写「小红书必须能接」。这里的语义拆成两层：

| 层级 | 要求 | 实现 |
|---|---|---|
| 入口 | 用户分享过来必须能存 | `route=parsehub`，降级 `kind='link'` |
| 内容 | 抓到标题封面正文 | 抓不到，原因写进 `error` |

**不能返回 `unsupported`**——那会让用户以为「存不进去」，是两件不同的事。

### 2.4 域名按标签边界匹配

`notdouyin.com` 不能被 `douyin.com` 命中。子串匹配是最容易踩的坑：

```python
def _matches(host: str, domain: str) -> bool:
    return host == domain or host.endswith("." + domain)
```

已有两条用例钉住（`notdouyin.com`、`douyin.com.evil.example`）。

## 四、顺手修掉的两个真缺口

### 4.1 `parsehub` 从未在 `pyproject.toml` 声明

本机能跑只因为环境里恰好装了。`pip install -e .` 出来的新环境会缺依赖。
已加 `parsehub>=2.4.4,<2.5`（2.4.4 是 R0 平板实测可用版本）。

### 4.2 `external` 标记未注册也没过滤

只写 `pytestmark = pytest.mark.external` 不做两件事，**默认全量照样跑外网**：

```
修复前：pytest -q → 240 passed（含 3 个外网用例）
        抖音改版就会让整个套件变红，掩盖真正的代码回归
修复后：pytest -q → 237 passed, 3 deselected
        pytest -q -m external → 3 passed
```

同时发现 `asyncio_mode` 写成 `[tool.pytest_asyncio]` **读不到**，必须放
`[tool.pytest.ini_options]`。警告一直在但测试照样绿，最容易被忽略的那类问题。

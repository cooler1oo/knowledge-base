## 1. 你的问题逐条回答

### 1.1 图文、文章能抓全吗

**部分验证，尚未得出结论。**

| 类型 | URL 形态 | 实测结果 | 结论 |
|---|---|---|---|
| 视频 | `/video/{id}` | 标题/封面/原视频/描述/作者/点赞全部拿到 | ✅ 已验证 |
| 图文 | `/note/{id}` | 302 到 `m.douyin.com/share/note/{id}`；页面有 4 个 `<img>`；`bodyLen` 仅 27 | ⚠️ **图能拿，文字未确认** |

**为什么不能下结论**：我只测了 1 个 note ID，而它恰好没有正文文字。**「文章能否抓全」必须用你实际收藏的图文/文章各 3 条来测**，这列为 G2b 关卡。

**三种可能，未区分**：

| 形态 | 特征 | 能否抓全 |
|---|---|---|
| 纯图片笔记 | 只有图，无文字 | 图可全部拿到 |
| 图文混合 | 图 + 描述文字 | 文字在 `meta[description]` 与 DOM 中，未验证完整性 |
| 长文章 | 抖音「笔记」形态 | 未验证 |

### 1.2 视频：能存原视频吗

**能。已实测下载成功。**

```
完整视频 URL（从 <video>.currentSrc 取）:
https://m.douyin.com/aweme/v1/playwm/?video_id=v0300fg10000c2egtqtovkemgno0u7o0&ratio=720p&line=0

curl 结果:
http=200  type=video/mp4  size=4076253  (3.9MB)
```

**两个必须的条件**（少一个就 404）：

1. 从渲染后的 `<video>.currentSrc` 取完整 URL，不能自己拼
2. 请求必须带 `Referer: https://www.douyin.com/`

### 1.3 实测拿到的字段清单

从 `https://www.douyin.com/video/6961737553342991651` 的真实输出：

### 1.4 时长拿不到（待解决）

`video.readyState` 为 0，说明视频流未加载，所以 `duration` 是 `null`。三个候选方案，**均未验证**：

1. 页面内 `video.load()` 后等 `loadedmetadata` 事件
2. 从页面内嵌的 `RENDER_DATA` 找
3. 下载后用 `ffprobe` 读文件（最可靠，多一次 IO）

列为 **G2c 关卡**，必须在真机上试出来。

### 1.5 摘要质量低，根因是什么

**不是模型差，是可摘的文本太少。**

抖音视频页的全部可读文本：

```
标题：#杨超越 小小水手带你去远航❤️
描述：与标题相同
正文：无（视频本身没有文字）
```

AI 摘要的输入只有一句话，输出只能是这句话的同义改写。**换任何模型都一样**——信息量只有这么多。

**三条改善路径**：

| 路径 | 效果 | 成本 |
|---|---|---|
| ASR 语音转文字 | 真正解决：把视频里说的话提出来 | 按分钟计费；本地 whisper 在平板算力上 ⚠️ 需实测 |
| 评论区摘要 | 评论区常有内容概括 | 额外抓取，可能触发风控 |
| 接受现状 | 靠标题+封面+时间检索 | 零成本 |

**这里要修正我 v3.0 的一处夸大**：你要的是「凭模糊记忆找回」，那么**标题 + 封面 + 时间**已经够用，摘要只是锦上添花。所以「摘要质量低」对你实际使用的影响，没有我说得那么大。

## 4. 抖音抓取设计

### 4.1 三条路径实测

| 路径 | 结果 | 报错原文 |
|---|---|---|
| yt-dlp `DouyinIE` | ❌ | `Fresh cookies (not necessarily logged in) are needed` |
| f2 `ABogus` 签名 | ❌ | `403 Blocked by ArgusSecurityPlugin Uifid Not Found` |
| **CDP + 移动 UA** | ✅ | 6 个字段拿到 |

**必须移动 UA**：桌面 UA 下 `body.innerText` 仅 366 字符，拿不到 `<video>`。

### 4.2 抓取流程

```python
async def extract_douyin(url: str) -> dict:
    kind = "note" if "/note/" in url else "video"
    page = await cdp.open_page(url, mobile_ua=True)
    await page.wait(10)                    # SPA 渲染，实测需 8-12s

    data = await page.eval("""({
      title: document.title,
      desc: document.querySelector('meta[name=description]')?.content ?? null,
      cover: [...document.querySelectorAll('img')]
              .map(i=>i.currentSrc||i.src)
              .find(s=>s && s.includes('douyinpic') && s.includes('sc=cover')) ?? null,
      vsrc: document.querySelector('video')?.currentSrc ?? null,
      imgs: [...document.querySelectorAll('img')]
              .map(i=>i.currentSrc||i.src)
              .filter(s=>s && s.includes('douyinpic')).slice(0,20)
    })""")

    out = {
        "kind": kind,
        "title": data["title"].removesuffix(" - 抖音"),
        "author": parse_author(data["desc"]),
        "published_at": parse_date(data["desc"]),
        "likes": parse_likes(data["desc"]),
        "cover_url": data["cover"],
    }
    if kind == "video" and data["vsrc"]:
        out["video_url"] = data["vsrc"]
        out["video_bytes"] = await download(data["vsrc"],
                                            referer="https://www.douyin.com/")
    if kind == "note":
        out["images"] = data["imgs"][:9]
    await page.close()
    return out
```

**三条硬约束**：

| 约束 | 原因 | 违反后果 |
|---|---|---|
| 移动 UA | 桌面 UA 无 `<video>` | 抓不到视频 |
| 封面/视频当场下载 | URL 带 `x-expires` 签名 | 过期 403 |
| 下载带 `Referer` | 无 Referer 被拒 | 404 |

### 4.3 时长提取（G2c，未验证）

```javascript
// 方案 1：等元数据
await new Promise(r => {
  const v = document.querySelector('video');
  if (v.readyState >= 1) return r();
  v.addEventListener('loadedmetadata', r, {once: true});
  v.load();
});
```

方案 2 从 `RENDER_DATA` 找；方案 3 下载后 `ffprobe`。三个都试，取能用的。

## 5. 为什么不用 karakeep

六条致命问题（经对抗审查确认）：

| # | 问题 |
|---|---|
| 1 | 覆盖度指标偷换（标签级 vs 契约级） |
| 2 | 移动端版本倒挂：官方 App 不认识 fork 新增类型，而采集入口就是那个 App |
| 3 | Termux 跑不了 Docker（Android 内核不向非 root 暴露 namespace） |
| 4 | fork 核心枚举是破坏性迁移，贯穿 zod→Drizzle→tRPC→OpenAPI→SDK→web→扩展→MCP→移动端 |
| 5 | 「1GB 内存」是 idle 观测，非预算值 |
| 6 | 上游升级使 rebase 成为经常性支出（0.33→0.34 即会话表迁移 + Chrome 镜像换代） |

**保留其架构参考**：资产存储/Search/Queue 的插件化抽象值得借鉴，但不套用产品。

## 6. 技术栈

| 层 | 选择 | 理由 |
|---|---|---|
| 后端 | Python 3.12 + **Starlette** | `pydantic-core`（Rust）无 Android 轮子，FastAPI 装不上 |
| 数据库 | Postgres 18.7（Termux 包） | 原生可用 |
| DB 驱动 | **pg8000**（纯 Python） | psycopg 是 C 扩展 |
| 密码哈希 | **bcrypt**（Termux 包） | argon2 bindings 是 C |
| 检索 | Meilisearch aarch64 | 官方静态二进制 |
| 抓取 | httpx + Chromium CDP | 静态用 httpx，抖音用 CDP |
| 前端 | TypeScript + React + Vite | 类型系统约束 |
| 安卓客户端 | Capacitor + Kotlin 分享桥 | 分享入口可靠性 |

**依赖替换实测依据**：

| 包 | Android 轮子 | Termux 预编译 | 结论 |
|---|---|---|---|
| psycopg / psycopg2 | 无 | 无 | 换 pg8000 |

| argon2-cffi-bindings | 无 | 无 | 换 bcrypt |
| markupsafe | 无 | 无 | 不用 Flask |
| lxml | 无 | ✅ python-lxml 6.1.3 | 用 Termux 包 |

## 一、五个最值得抄的产品

### 1. Karakeep（原 Hoarder）— 开源，25k stars，最接近本项目形态

定位：「什么都存」的自托管书签库。

| 能力 | 说明 |
|---|---|
| 自动抓取 | 标题、描述、封面图自动获取 |
| AI 标签 + 摘要 | 支持 OpenAI，也支持本地 Ollama（数据不出门） |
| 全文 + 语义搜索 | 基于 Meilisearch，容错、快，几千条秒出 |
| **整页存档** | 用 monolith 把整页 HTML 存下来，防链接失效 |
| **视频归档** | 用 yt-dlp 自动下载视频（可选） |
| OCR | 图片里的文字也能搜 |
| 规则引擎 | 「来自某站点的都打某标签」这类自动规则 |
| 多端入口 | Chrome/Firefox/Safari 插件 + iOS/Android App（支持系统分享菜单） |
| 离线阅读 | 手机端可离线看已存内容 |
| RSS 自动收录 | 订阅源新文章自动进库 |
| 高亮 | 在收藏内容上划线做标注 |
| 列表 / 收藏 / 归档 | 三态区分：正常 / 星标 / 已处理 |
| 批量操作 | 多选改标签、移动、删除 |
| 导入器 | Chrome 书签、Pocket、Omnivore 等 |
| API / CLI / Agent Skills | 可被 AI agent 调用 |

**对本项目的启示**：这是一个已经跑通的完整答案，把「防丢失」和「自动整理」做到了产品级。我们要做的是它的子集 + 更符合中文习惯的入口。

### 2. Cubox — 中文场景最强对标（付费）

| 能力 | 说明 |
|---|---|
| **微信转发收藏** | 发给指定账号即可收藏，这是中文用户的默认入口 |
| 正文解析 | 独家算法去广告，输出干净排版 |
| 快照存档 | 永久保存，原文删了还能看 |
| 高亮 + 标注 | 多彩色高亮，记录想法 |
| **标注漫游** | 滑动卡片回顾以前划过的高亮（回顾机制） |
| AI 自动总结 | 摘要 + 提出关键问题 |
| 幻影高亮 | AI 自动找出文中精彩句子 |
| **AI 自动关联** | 跨文章发现相似主题的新线索 |
| **全库问答** | 「一句话找到 5 年前收藏的任何段落」 |
| 智能清单 | 多维度规则自动筛选（不是死文件夹） |
| 嵌套分类 + 标签 | 两层结构，可自由搭建 |
| 分词模糊搜索 | 中文分词，记得一点点也能搜到 |
| 图片/音视频文字化 | 非文本内容也能用文字搜 |
| 定时 AI 报告 | 定期生成知识摘要推送 |
| 导出 | Markdown / HTML / PDF，可同步 Obsidian、Notion |
| 开放 API | URL Schemes |

**启示**：中文场景的胜负手是**微信入口**和**中文分词搜索**。这两件事英文产品全都不做。

### 3. Readwise Reader — 「回顾」这件事的教科书（$7.99/月起）

| 能力 | 说明 |
|---|---|
| **每日回顾 Daily Review** | 每天推几条旧高亮，间隔重复，逼你回看 |
| 高亮一切 | 文字、图片、表格、YouTube 字幕都能划 |
| Ghostreader AI | 问答、解释术语、翻译、摘要 |
| 全文搜索 | 极快，离线也能搜 |
| TTS 朗读 | 任何文档转语音听 |
| 本地优先 | 离线可用，联网再同步 |
| MCP Server / API | 让 Claude、ChatGPT 直接读你的库 |

**启示**：知识库真正的价值不在「存」，在「重复遇到」。Daily Review 是唯一被验证有效的机制。

### 4. Eagle — 视觉素材管理的标杆（买断制）

| 能力 | 说明 |
|---|---|
| **颜色筛选** | 只记得「大概是蓝色」，直接选色票找图 |
| 以图找图 | 从一张图找相似风格 / 原始来源 |
| 智能文件夹 | 按名称、标签、颜色、格式自动归类 |
| **重复/相似文件扫描** | 找出重复素材合并，省空间 |
| 随机模式 | 随机排列，重新发现忘掉的收藏 |
| 自动标签 | 给文件夹预设标签，进来的素材自动带上 |
| 星级评分 | 打分后按星级筛 |
| 标签分组 | 标签太多时分组管理 |
| 密码保护 | 私密文件夹上锁 |
| 100+ 格式预览 | 视频、音频、字体、PSD 都能直接看 |

**启示**：图片类收藏的检索维度不只是文字——**颜色、比例、格式、相似度**都是人被记住的线索。

## 二、完整功能池（按「五层」归类 + 优先级）

优先级：**P0 = 没有就不是知识库**，P1 = 决定好不好用，P2 = 决定会不会爱上，P3 = 成本高/依赖大

### 1. 收得进来（入口）

| 功能 | 优先级 | 备注 |
|---|---|---|
| 网页粘贴链接即存 | P0 | 最基础 |
| 浏览器插件（存页面/存链接/存选中片段/截图） | P0 | 电脑端主力 |
| 手机系统分享菜单 | P0 | 手机端主力，微信/抖音/小红书都能「分享→存」 |
| 拖拽上传图片/文件 | P1 | |
| 剪贴板直接粘贴截图 | P1 | 截图党刚需 |
| 批量导入（浏览器书签 HTML、旧收藏） | P1 | 有存量才需要 |
| RSS 订阅自动收录 | P2 | |
| 邮件转发入库 | P2 | |
| **微信转发/服务号收藏** | P1 | 中文场景命脉，但实现有门槛 |

### 2. 存得住（防丢）— 当前最大空白

| 功能 | 优先级 | 备注 |
|---|---|---|
| 抓正文全文 | P0 | 全文是搜索的地基 |
| 抓封面图并本地保存 | P0 | 防外链失效 |
| 生成 100 字摘要 | P0 | 链接挂了也能知道存过啥 |
| **整页快照存档** | P1 | 防删防改，存储成本可控（压缩 HTML） |
| 视频抓字幕（B站约 60% 有字幕、YouTube 约 80% 有自动字幕 ⚠️二手数据） | P1 | 有字幕就用原生，省算力 |
| 无字幕视频用 ASR 转录（Whisper 类，中英 ≥95% ⚠️二手数据） | P2 | 有算力成本 |
| 视频抓封面 + 时长 + 简介 | P1 | |
| 视频原文件可选下载 | P2 | 用户手动选择，不默认 |
| 图片 OCR（截图里的字可搜） | P1 | 截图党价值极大 |
| 图片 AI 描述（「蓝色海报」可搜） | P2 | |
| 重复检测（同一链接存两次） | P2 | |
| 处理失败可重试 + 失败原因可见 | P0 | 不显眼但决定信任 |

### 3. 找得到（检索）

| 功能 | 优先级 | 备注 |
|---|---|---|
| 全文搜索（标题/正文/摘要/我的笔记） | P0 | |
| 中文分词 + 错字容忍 | P0 | 中文场景关键，不能用英文那套 |
| 筛选器组合（形态 + 标签 + 时间 + 来源 + 看没看过） | P0 | |
| 语义搜索（记得意思不记得词） | P1 | 需 embedding，每条一次模型调用 |
| 分类内搜索 | P1 | |
| 按颜色找图 | P2 | Eagle 的做法 |
| 以图找图 / 相似图 | P3 | 技术成本高 |
| 搜索词高亮 + 命中位置跳转 | P1 | 体验分水岭 |
| 搜索历史 / 常搜词 → 可固化成入口 | P2 | |

### 4. 记得起（回顾）— 当前最大空白

| 功能 | 优先级 | 备注 |
|---|---|---|
| 时间轴浏览（按周/月） | P1 | 「想起哪天看的」 |
| **随机漫游**（随机推几条旧收藏） | P1 | 成本极低，效果极好 |
| 每日回顾（每天推 3-5 条） | P2 | Readwise 验证过有效 |
| 未读清理（滑卡片，一次清一批） | P2 | Cubox 的做法 |
| 「去年同期你存了什么」 | P3 | |
| 高亮/标注回顾 | P2 | |
| 长时间没打开过的内容提醒 | P3 | |

### 5. 用得上（输出）

| 功能 | 优先级 | 备注 |
|---|---|---|
| 单条问答（对这篇文章/视频提问） | P2 | |
| 全库问答（「我以前存过关于X的什么」） | P2 | RAG，是「知识库」和「收藏夹」的分界 |
| 视频章节化摘要（带时间戳） | P2 | |
| 生成合集/清单 | P2 | |
| 导出 Markdown / PDF / 图片 | P1 | 防锁定，必须早做 |
| 分享单条 / 合集 | P2 | |
| **MCP / API 开放给 AI agent** | P3 | 2026 新趋势，Karakeep 和 Readwise 都有 |

### 6. 整理（用户可控）

| 功能 | 优先级 | 备注 |
|---|---|---|
| 形态大类（文章/图文/视频/图片/文件/音频/链接） | P0 | 固定不可改 |
| 主题标签，可自建、可嵌套一层 | P0 | |
| 自动打标签 + 一键改（改后记住规则） | P0 | |
| 智能清单（按规则自动筛，替代死文件夹） | P1 | Cubox / Eagle 都有 |
| 批量操作（多选改标签/删除/归档） | P1 | |
| 规则引擎（「来自B站的都归影音+打视频标签」） | P2 | |
| 收藏 / 归档 / 回收站 三态 | P1 | |
| 星级评分 | P3 | |
| 私密内容 / 密码保护 | P3 | |

### 7. 地基（不显眼但决定生死）

| 功能 | 优先级 | 备注 |
|---|---|---|
| 双端同步（电脑 + 手机一致） | P0 | |
| 数据导出 / 备份 | P0 | 防止被锁死，也是信任基础 |
| 异步处理（存的时候秒回，标签稍后出现） | P0 | 同步等待会让人弃用 |
| 全文索引 | P0 | |
| 离线可用（至少能看已存的） | P2 | |
| 账号 / 登录 | P1 | 单人也需要，多端必须 |

## 三、三阶段落地建议

### 阶段一：能存能找（MVP）

- 网页粘贴链接存（抓标题 + 封面 + 正文 + 摘要）
- 上传图片存（OCR 出文字）
- 自动判形态（按内容结构，不按域名）
- AI 打 1-3 个主题标签 + 一键改 + 记住规则
- 列表浏览（封面网格 / 列表两种视图）
- 全文搜索（中文分词）
- 手机浏览器能打开、能搜、能看
- 数据可导出

**不做**：入口按钮、语义搜索、每日回顾、全库问答、视频下载、颜色搜索

### 阶段二：好用了

- 浏览器插件 + 手机分享菜单（补入口）
- 整页快照存档
- 视频字幕抓取 + 章节摘要
- 语义搜索
- 随机漫游 + 时间轴
- 批量操作 + 智能清单

### 阶段三：用得上

- 全库问答（RAG）
- 图片颜色筛选 / 相似图
- 每日回顾
- RSS / 微信转发
- MCP / API

## 四、成本与风险

| 项 | 估计 | 说明 |
|---|---|---|
| 模型调用 | 每条内容 1-3 次调用，几千条约几元到几十元 | 摘要 + 标签 + 向量 |
| 对象存储 | 图片/封面为主，视频原文件才吃空间 | 100MB 视频约几分钱/月 |
| 全文索引 | 个人量级无需额外成本 | |
| 快照存档 | 压缩 HTML，单条约 100-500KB | 一千条约 100-500MB |
| 视频转录 | 按分钟计费，1 小时视频约几毛钱 | 只对无字幕视频启用 |

**三个真实风险**

1. **链接失效无法 100% 解决**：快照能救正文，救不了交互式页面和视频。只能降低损失。
2. **AI 标签一定会错**：所有产品都错，区别只在于改起来是否方便。不要指望「准确」，要设计「好改」。
3. **存了不看是通病**：这是所有知识库的头号死因，跟功能多少无关。阶段二必须有回顾机制，否则做再多入口也是往黑洞里扔。

## 五、几个还没答案的问题

1. 中文公众号文章的反爬强度，决定「抓正文」的可行度——需要实测再定方案。
2. 微信入口（转发收藏）需要公众号或企业微信通道，个人项目实现成本高，需评估。
3. 手机端是做成 PWA（浏览器打开、可加桌面图标）还是原生 App，影响开发量和上架成本。
4. 视频转录用云端 API 还是本地模型，影响成本和隐私。
